# Reference-to-original design matrix

The goal is to learn *systems* from legally accessible observation/documentation, not to extract or publish protected assets.

| Reference | Observed design element | EVERBLOOM distinct implementation |
|---|---|---|
| Harvest Moon: Tree of Tranquility | Farm+animals, island community, relationships/family, part-time jobs, festivals, long-term nature restoration | Original Larkspur Valley, tree-planting guild, wildwood restoration and community economies |
| Harvest Moon: Echoes of Teradea | Farm/adventure blend, larger world, animal-companion exploration and multiple regions | Multiple original biomes, glider/skiff travel, rescuable wildlife and weather-linked caves |
| Other classic farming sims | Daily effort/reward, player expression, seasonal rhythm | Player-authored homestead, regional soil identities, multigenerational town simulation |

No Nintendo/Natsume/Marvelous trademarked character or original game asset is used here. Their registered titles appear only as comparative source references.
