# Original SABLESTAR source assets

This directory contains original source art, six authored vector icon/crest assets,
a six-part faceted Sableblade OBJ/MTL model, and two generated PCM WAV cues.
All mesh and sound sources are reproducible with `python tools/generate_original_assets.py`.
The SVG illustrations were authored specifically for this project. No proprietary
assets from Kingdom Hearts, Donkey Kong, Final Fantasy, Baldur's Gate, Elden Ring,
Skyrim, Zelda, Resident Evil, or any other third-party game are included.

`assets/provenance.json` identifies every source asset by size and SHA-256.
Source art may be imported into Godot; editor import/quality and actual visual
rendering must be independently verified before being reported complete.

For analysis of third-party assets, use only accessible files you have the
necessary rights to inspect. Store findings separately from shipping assets.
