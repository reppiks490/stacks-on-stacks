# AAA comparative research → independent AA game engineering

## Scope

The following references inform a **feature taxonomy**; none is a claim to have reverse-engineered executable binaries or original proprietary source. Research should distinguish documented gameplay, user-observed behavior, extracted executable evidence (if properly authorized), hypotheses, and a separately implemented original design.

- Kingdom Hearts IV: public footage and material only until release; not a released executable in November 2026.
- Donkey Kong Bananza: local material fracture, impact traversal and legible environmental feedback.
- Final Fantasy XV: companion behavior, contextual interactions, on-foot-to-vehicle traversal.
- Baldur's Gate 3: branching flags, reactive quests, systemic combat interactions and dialogue graph.
- Elden Ring: stamina/readability, hit telegraphs, encounter tiers and field discovery.
- Skyrim/The Elder Scrolls: systemic factions, discoverable spaces, persistent quest state and simulation feel.
- Zelda: Breath of the Wild / Tears of the Kingdom: emergent sandbox interactions, combinatorial objects, environmental puzzles and navigation.
- Resident Evil Requiem (the latest numbered mainline entry in 2026): tension pacing, encounter readability, resource scarcity and systemic sound.

## Evidence ladder

1. **Public design**: official game guides, developer talks, patent/technical documents, public demonstrations; exact citations per claim.
2. **Authorized profiling**: performance traces, frame pacing, behavior measurements from legally acquired games, without distribution of copies or protected assets.
3. **Permitted static analysis**: where authorized and legally permissible, REA/Ghidra/disassembly findings with target/version/function-hash provenance; no DRM/anti-cheat circumvention or protected online services.
4. **Hypothesis/reproduction**: isolated test fixture with original code and pass/fail criteria; uncertain hypotheses remain uncertain.
5. **Production acceptance**: instrumented native engine performance, controller/mobile accessibility and full build evidence.

## Original game adaptation policy

Transfer **mechanical abstractions**: e.g. poise windows, systemic material response, dialogue consequence flags, companion utility and equipment limits. Do **not** reuse protected characters, maps, storylines, music, voice clips, textures, model meshes, or proprietary source. REA cannot recover unreleased game source (Kingdom Hearts IV), external online server code or encrypted assets by asking it to.

## Tooling boundary

REA's official materials identify `morluto/rea` and `rea-agents` as official channels. Do not install or enable any Codex integration for this project. Any future extraction request requires identification of specific, locally available, lawfully accessible target artifact and explicit limitations. This repository contains no external executable samples.
